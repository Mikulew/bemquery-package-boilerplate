# bemquery-package-boilerplate

Simple boilerplate from Comandeer's book "JavaScript – Advanced programming"

---

## Installation

You can install this package from npm:
```bash
npm install bemquery-package-boilerplate [--save]
```

You can also install it from bower:
```bash
bower install bemquery-package-boilerplate
```

## Documentation

Docs are available at http://mikulew.github.io/bemquery-package-boilerplate
